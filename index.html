01 / ABOUT

A different path. A new direction.

My journey into technology didn't begin with a computer science degree.

Instead of simply learning theory, I wanted to understand by building. So I started creating websites, experimenting with HTML and CSS, learning JavaScript, using GitHub and exploring AI-powered development tools.
